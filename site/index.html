Never miss an LMS deadline again.

notlms runs on your own computer, checks your Moodle LMS for tasks you haven't submitted, and pops up a desktop reminder before they're due. Free and open source. No account, no server, no tracking.

How it works

Your LMS

There is no notlms server in this picture. That's the point.

  1. You log in once on a page that notlms opens on your own computer (127.0.0.1, not the internet). Your password goes to your LMS to get an access token, then it's discarded.
  2. It checks your LMS every 30 minutes (configurable) for work that still needs action, and ignores submission links for other sections.
  3. It reminds you with a native desktop notification when a task is new, then at 72, 24, 6 and 1 hours before the deadline, and once more if it's overdue and still open. Each reminder is sent once.
  4. The dashboard shows everything pending, with course name, deadline and time left.

Reminders only appear while notlms is running and your computer is awake. After your computer wakes up, the next check announces anything you missed.

Privacy: what we do with your data

We collect nothing

No server, accounts, analytics or telemetry. The authors never receive any of your data.

Password: used once

Sent only to your LMS to get a token. Never saved to disk.

Token stays local

Stored in a file in your user folder. "Forget everything" deletes it, and you can revoke it in your LMS.

Auditable

Small, readable code with no third-party dependencies. Read it, or build it yourself.

Be aware: a Moodle token can do what the Moodle mobile app can do on your account, so keep your computer account secure. notlms only reads your pending tasks. It never submits anything. Full details and the exact files that make network calls are in PRIVACY.md.

Setup

  1. Download the file for your system above.
  2. Open it (see your system below). A terminal window opens and your browser shows the notlms page. Keep that window open: closing it stops the reminders.
  3. Log in with your LMS username and password. Set your section (for example B) so you only see your own submission links.
  4. Press "Send test notification" to confirm reminders appear on your desktop.
  5. Start it whenever you turn on your computer, or add it to your startup apps so you don't forget.

Windows

Double-click notlms-windows-x64.exe. If you see "Windows protected your PC", click More info, then Run anyway. Make sure notifications aren't blocked by Focus Assist.

macOS

Unpack the .tar.gz (double-click it), then in Terminal run:

cd ~/Downloads && xattr -d com.apple.quarantine notlms && ./notlms

Or right-click the notlms file, choose Open, then confirm. Pick the arm64 file for Apple silicon (M1 and newer) and x64 for Intel Macs. If notifications don't show, allow them for "Script Editor" in System Settings, then Notifications.

Linux

tar -xzf notlms-linux-x64.tar.gz
./notlms

Desktop notifications need notify-send (package libnotify-bin or libnotify).

Run from source instead

Needs Python 3.12 or newer and nothing else:

git clone https://github.com/__REPO__.git
cd notlms
python3 -m notlms

Verify your download

Check the file against the SHA256SUMS published with the release:

sha256sum -c SHA256SUMS --ignore-missing      # Linux
shasum -a 256 -c SHA256SUMS --ignore-missing  # macOS
certutil -hashfile notlms-windows-x64.exe SHA256   # Windows, compare by eye

Or prove it was built from this repository's public code by GitHub Actions (needs the GitHub CLI):

gh attestation verify <downloaded-file> --repo __REPO__

FAQ

Does it work with my university?

It's built for NUST's LMS but uses the standard Moodle mobile API, so other Moodle sites that allow mobile app login should work: enter their address on the login page. Sites that only offer single sign-on (no username and password on the login form) aren't supported yet.

Can it submit my assignments or read my grades?

No. It only reads the list of tasks that still need action.

Why no reminders when my laptop is off or asleep?

Everything runs on your computer, and there's deliberately no server to do it for you. After it wakes, the next check shows what you missed.

The app is "unsigned". Is it safe?

Unsigned means we haven't paid for a publisher certificate, not that it's unsafe. You can read the source, verify the download was built from it, or run from source.

How do I uninstall it?

Click "Forget everything and log out" in the app, delete the downloaded file, and delete the notlms folder in your user data directory (see the privacy section). Nothing else is installed on your system.

Something broke. Where do I report it?

Open an issue on GitHub. For security problems use the private "Report a vulnerability" option instead.
